Project Overview Presentation

What is the PTB-XL Dataset?

  • Large Scale: A major dataset comprising 21,837 clinical 12-lead ECG records.
  • Patient Diversity: Data collected from 18,885 unique patients.
  • Duration: Each recording is exactly 10 seconds long.
  • Annotation: Interpreted by cardiologists according to the SCP-ECG standard.
  • Format: Stored in WFDB format with 500Hz & 100Hz sampling.

Demographics: Age Groups & Sex

Analysis of the patient population reveals key demographic trends critical for model training:

  • Distribution: Significant concentration in older age groups (60-79 years).
  • Gender Balance: Males vs Females. Males are more dominant in pathological groups.
  • Impact: This skew must be addressed during training to prevent bias.

Arrhythmia Class Distribution

Class Imbalance

Our dashboard analysis highlights a severe class imbalance, a common challenge in medical datasets.

  • Dominant Classes: Normal (NORM) and Sinus Rhythm (SR) constitute the majority.
  • Rare Classes: Pathologies like AFLT (Atrial Flutter) are underrepresented.
  • Solution: Requires weighted loss functions.

Sex Distribution by Arrhythmia Class

Gender Disparities in Diagnosis

This chart breaks down the male/female ratio for each specific arrhythmia class.

  • SR (Sinus Rhythm): Shows a roughly balanced gender distribution.
  • Pathologies: Certain conditions like Ischemic Heart Disease (often associated with MI) may show a higher prevalence in males in this dataset.
  • Insight: Models must be robust against spurious correlations.

Metadata Architecture (CSV)

SCP Codes

Standardized diagnostic codes per record (e.g., 'AFIB': 100.0). Supports multi-label classification logic.

Demographics

Patient ID, Age, Sex, Height, and Weight. Missing values are sanitized (NaN handling) via MATLAB scripts.

Signal References

Pointers to raw high-resolution (500Hz) and low-resolution (100Hz) WFDB signal files.

Dynamic Filtering Logic

  • Criteria-Based Selection:
    Interactive UI allows selection by age range, sex, and specific arrhythmia type.
  • Backend Processing:
    ptbxl_read_metadata.m scans CSV using logical indexing for O(1) access speed.
  • Real-Time Visualization:
    Histograms update instantly to reflect the selected sub-population's statistics.
  • Deep Dive:
    Allows isolation of specific cases (e.g., "Females under 40 with MI") for detailed review.

Prototype: Metadata Classification

Baseline Model: Normal vs Abnormal

Before deep learning, we established a baseline using ptbxl_simple_model.m based purely on metadata.

Insight: The graph clearly shows that "Abnormal" cases (Teal) have a much wider and older age distribution compared to "Normal" cases. This proves that age is a highly discriminative feature even for simple logistic regression.

Disease Co-occurrence Matrix

Correlations Between Classes

Using Jaccard Similarity in ptbxl_data_analysis.m, we mapped how often different arrhythmias occur together.

Interpretation:
